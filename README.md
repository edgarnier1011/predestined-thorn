Unity Cutscene Project

Note: This repository is intended for portfolio and demonstration purposes.

Project Overview

This repository demonstrates how I structured and organized a cutscene sequence for a video game developed using Unity.

The complete cutscene consists of three parts. However, only the first part is included in this repository to showcase the project’s organization and implementation.

The project is divided into two primary folders: Terrain and Timeline.

⸻

1. Project Structure

Terrain

The Terrain folder contains the environmental assets and objects used to construct the cutscene’s setting.

These include:

* Terrain and landscape elements.
* Trees and vegetation.
* Grass and other environmental details.
* Sky and background elements.

This separation allows the environment to be managed independently of the cutscene’s events and animations.

Timeline

The Timeline folder contains the objects and sequences responsible for the progression of the cutscene.

This includes:

* Character animations and interactions.
* Sequencing and timing of events.
* Camera positioning and transitions.
* Coordination of the different elements involved in the cutscene.

Unity’s Timeline system is used to organize and control these sequences, providing a structured approach to cinematic development.

⸻

2. Project Purpose

This repository serves as a portfolio project demonstrating experience with:

* Unity scene organization and project structuring.
* Environmental design and asset management.
* Cinematic sequencing using Unity Timeline.
* Camera coordination and transitions.
* Cutscene development and implementation.

The separation between environmental assets and cinematic sequences helps maintain a modular and organized project structure.
